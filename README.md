# PERSONAL HQ — Business Edition

Личное веб-приложение для целей, планирования, дневника, проектов, финансов и привычек.

## Запуск локально
Просто открой `index.html` в браузере. Никакие npm-пакеты или сборка не нужны.

## Публикация через GitHub Pages
1. Создай новый публичный репозиторий на GitHub, например `personal-hq`.
2. Загрузи `index.html` и `README.md` в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку **main** и папку **/(root)**, нажми **Save**.
6. Подожди завершения публикации. GitHub покажет ссылку вида `https://ТВОЙ-ЛОГИН.github.io/personal-hq/`.

## Важно про сохранение данных
- Записи хранятся локально в браузере на устройстве (localStorage).
- Для переноса на другое устройство используй кнопки экспорта и импорта JSON в верхней панели на компьютере.
- Не очищай данные браузера, пока не сделал резервную копию.
- Это личное приложение без аккаунтов и синхронизации между устройствами.

## Функции
- Dashboard с ключевыми показателями и динамикой доходов
- Цели со сроками и статусами
- Задачи на каждый день
- Личный дневник с оценкой дня
- Проекты и следующие действия
- Учёт доходов и расходов в гривнах
- Привычки
- Хранилище идей и еженедельные/месячные обзоры
- Анимации интерфейса, адаптация под телефон и компьютер
